# FREE FIRE SENSI AI PRO

تطبيق أندرويد بسيط باللغة العربية لاقتراح وتجربة إعدادات حساسية Free Fire، مع حفظ ملفات إعدادات متعددة.

## البناء السحابي عبر GitHub Actions
1. أنشئ مستودع GitHub جديداً باسم `free-fire-sensi-ai-pro`.
2. ارفع جميع ملفات هذا المشروع إلى المستودع، مع الحفاظ على المسارات، واجعل الفرع اسمه `main`.
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build Android APK** ثم **Run workflow** إن لم يبدأ البناء تلقائياً بعد الرفع.
5. انتظر حتى يكتمل الـ workflow بنجاح.
6. افتح نتيجة التشغيل، وانزل إلى **Artifacts**، ثم نزّل `FREE-FIRE-SENSI-AI-PRO-debug-apk`.
7. فك ضغط الملف الذي نزلته لتحصل على `app-debug.apk`، ثم افتحه على هاتف أندرويد للتثبيت.

## ملاحظات
- هذا مشروع مصدر، وليس APK مبنياً مسبقاً.
- APK الناتج نسخة debug للتجربة.
- التطبيق لا يتصل بلعبة Free Fire ولا يغيّر ملفاتها؛ يعرض إعدادات مقترحة ويحفظ ملفاتك محلياً.
- القيم المقترحة نقطة بداية فقط وليست ضماناً لتحقيق Headshots.
